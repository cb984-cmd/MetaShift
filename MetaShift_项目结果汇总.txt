MetaShift-Bench 项目结果汇总
=============================

项目题目
--------
中文：MetaShift-Bench：基于元数据锚点与跨站反事实的空气质量监测方法转换审计基准
英文：MetaShift-Bench: A Metadata-Anchored Counterfactual Benchmark for
      Auditing Measurement-Method Transitions in Air-Quality Networks

当前定位
--------
本项目的主线是可复现审计基准，而不是“MetaShift算法显著优于所有基线”。

最重要的结论边界：
1. AQS Method Code变化是“报告的测量方法变化”的元数据锚点。
2. 它不证明物理仪器一定更换，也不证明已确认的校准故障或测量偏差。
3. 跨站反事实得到的是与方法转换相关的局部残差不连续性证据，不是真实污染浓度
   修正值，也不能单独确定物理成因。
4. MetaShift的算法优越性路线已经按预先规则关闭：其MAE点估计有时较低，但相对
   Standard synthetic control的配对bootstrap置信区间跨过0，且归因指标较弱。
5. 本文件中的合成结果来自已修复完整输入拆分后的两次独立重建；34个核心结果文件
   的SHA-256完全一致。安全证据包已发布为v0.2.0-paper-evidence，并排除原始数据、
   API响应与凭据。

数据与事件规模
--------------
主数据：EPA AQS参数88101，2019--2025，PM2.5 Local Conditions。
主日度信号：24-HR BLK AVG的Arithmetic Mean。
保留条件：Observation Percent >=75，Method Code非空，Event Type不为Excluded。

- 规范化日度记录：2,424,793
- 监测器时间序列：1,689
- Method Code连续运行段：2,382
- 初始合格的持续方法转换锚点：563
- 至少1个地理供体的锚点：394
- 至少3个地理供体的锚点：271
- 同址替代POC候选：11

事件条件：
1. 转换前后均至少60个日历日；
2. 前后各至少45条符合质量门槛的日度观测；
3. 相邻方法运行段间断不超过7天。

地理供体条件：
1. 位于不同物理站点，距离不超过100 km；
2. 在目标事件+/-60天内自身没有Method Code转换；
3. 至少60个转换前配对日；
4. 转换前log(1+PM2.5)相关系数至少0.60。

稳定区间合成基准
----------------
早期“在真实转换日期注入合成偏差”的试验已淘汰，不用于论文结论。最终基准只在
目标站与供体站均远离Method Code转换至少60天的稳定区间建立伪锚点。

拆分与独立性：
- 146个不同物理站点；
- 66个物理站点用于阈值校准；
- 80个物理站点用于独立评测；
- 校准与评测的完整输入足迹（每个目标及其选中供体）没有任何物理站点重叠；
- 每种局部或匹配区域扰动变体有400个独立评测样本；
- 每种方法有4,000个评测实例；
- 每个局部效应方法有1,600个带幅度真值的评测实例；
- 阈值只在校准站选择，原样用于评测站；
- 主基准与消融的7,300条共同Standard synthetic-control记录逐行完全一致，
  estimated_log_effect、absolute_effect_error与ranking_score最大差异均为0.0。

扰动类型：
1. 局部固定水平跳变；
2. 局部比例变化；
3. 局部缓慢漂移；
4. 局部暂时性偏差；
5. 局部方差变化；
6. 对应的区域共同冲击。

稳定合成基准主结果
--------------------
MAE单位为log(1+PM2.5)，越低越好；AUPRC和Macro-F1越高越好；区域FPR越低越好。

方法                         MAE       AUPRC     Macro-F1    区域FPR
--------------------------------------------------------------------------
Standard synthetic control   0.10772   0.90956   0.82788     0.053
MetaShift fixed-prior        0.10483   0.88837   0.78849     0.142
MetaShift CV                 0.10335   0.89484   0.79757     0.144
Nearest-neighbor DiD         0.11536   0.87035   0.76987     0.168
Bayesian mean shift          0.23148   0.50118   0.49965     0.465
Before-after median          0.24169   0.50132   0.50096     0.447
CUSUM                        无幅度估计 0.50154   0.50124     0.503
PELT                         无幅度估计 0.50203   0.50122     0.475
Rolling-MAD                  无幅度估计 0.49983   0.49580     0.432

算法优越性检验：
- MetaShift fixed-prior - Standard SC的MAE差异：-0.00289，
  95% CI [-0.01095, 0.00412]；
- MetaShift CV - Standard SC的MAE差异：-0.00437，
  95% CI [-0.01138, 0.00208]。

两个区间均跨过0。MetaShift CV的MAE点估计略低，但不能据此宣称显著或稳定优于
Standard synthetic control。Standard SC在综合AUPRC、Macro-F1和区域误报率上
更强，因此算法优越性路线关闭。

关键消融和参数敏感性
--------------------
1. 可靠性消融：
   相关性、距离、覆盖率、图先验与ridge正则均会改变点估计，但没有单一组件相对
   Standard SC显示稳定、置信区间支持的优势。

2. ridge强度：
   完整消融同时报告ridge=0、0.01、0.1和1.0；不只报告最优值。

3. 真实事件窗口：
   每个窗口重新核对目标前后方法段和所有固定供体。45天窗口有258/261个完整事件，
   相对60天方向一致率94.2%；90天窗口有225/261个完整事件，方向一致率96.0%。
   MetaShift固定先验中位log效应分别为-0.07552、-0.07093和-0.06908。45天有3个、
   90天有36个事件因方法段不稳定或观测不足而明确标为不可用。

4. 数据门单因素网格：
   在要求至少3个供体时：
   - 主设置：271个锚点；
   - 覆盖率70% / 75% / 80%：275 / 271 / 266；
   - 稳定窗口45 / 60 / 90天：284 / 271 / 250；
   - 转换间断3 / 7 / 14天：238 / 271 / 290；
   - 距离50 / 100 / 200 km：127 / 271 / 446；
   - 相关性0.50 / 0.60 / 0.70：275 / 271 / 262；
   - 最少供体1 / 3 / 5：394 / 271 / 186。

结论：供体半径与供体数量是覆盖率的主要限制；不同合理规则下可审计事件数变化，
但“并非所有Method Code锚点都能可靠构造跨站反事实”的主结论稳定。

风险--覆盖率
------------
在有合成真值的独立评测站中，预拟合RMSE门控显示了真实的风险--覆盖率权衡。
以Standard SC为例，按校准集90%分位数设门后，保留73/80个评测站，局部效应
MAE为0.09152；全80站覆盖时MAE为0.10772。

真实事件没有物理偏差真值，因此真实数据中的Coverage只表示“可获得充分供体和
诊断证据的比例”，不能解释成真实准确率。

563个真实Method Code转换的观察性审计
-----------------------------------------
所有563个初始合格锚点均进入审计，不只展示成功案例。

审计状态                                  数量
------------------------------------------------
完成全部共同方法比较                       261
地理供体少于3个                           292
完整校准或比较窗口不足                     10
总计                                      563

在261个可比较事件中：
方法                         中位有符号log效应   中位绝对标准化分数
----------------------------------------------------------------------------
MetaShift fixed-prior        -0.07093            0.91923
Standard synthetic control  -0.06418            0.81345
Nearest-neighbor DiD        -0.06894            0.81737

不确定性与供体敏感性：
- 固定权重条件区间：MetaShift / Standard SC / DiD排除0的事件数为
  182 / 166 / 154（总数均为261）；
- 选择感知嵌套bootstrap：261个事件各运行1,000次；在每次中重采样时间块、
  重算供体相关性、重新选3--5个供体、重拟合权重；
- 选择感知MetaShift区间排除0的事件数为170/261，低于固定权重条件区间的182/261，
  表明供体选择不确定性使结果更保守；
- 260个事件完成所有leave-one-donor-out重新拟合；其中238/260（91.54%）移除
  任一单一供体后保持效应方向；
- 1次供体移除后数据不足，明确记录为不可估计。

时间安慰剂、FDR与证据等级
--------------------------
- 149/261个完整事件至少有50个不重复、方法稳定且数据完整的转换后伪日期；
- 其中120个事件有100个伪日期；
- 53个事件原始经验p<=0.05，70个p<=0.10，91个p<=0.20；
- 149个可筛查事件中，41个通过Benjamini-Hochberg q<=0.10探索性筛查；
- 200次日期重采样的全局上尾p=0.004975：真实锚点的平均分数高于稳定后伪日期；
- 1,050条donor-as-treated安慰剂记录，伪处理站标准化分数中位数为0.46802。

主证据层级要求：
1. 完整跨站比较且通过预拟合质量门；
2. 选择感知95%区间不跨0；
3. 至少50个独立时间安慰剂，原始p<=0.10且BH q<=0.10；
4. 至少90%的leave-one-donor-out结果保持方向。

证据等级结果：
- Supported candidate discontinuity：36
- Not supported by available evidence：113
- Inconclusive / insufficient evidence：414

严格（p<=0.05、供体方向稳定>=95%）、主设置（p<=0.10、>=90%）和宽松
（p<=0.20、>=80%）三组阈值的结果数量相同：36 / 113 / 414。原因是共有的
BH q<=0.10条件是当前主要限制。以上为观察性审计证据等级，不是已确认仪器故障
或物理因果标签。

外部证据
--------
1. 同址POC：
   - 11个同址替代POC候选具备前后配对记录；
   - POC不是统一物理设备编号，不能当作绝对设备真值。

2. EPA QA collocation：
   - 6条候选请求为API错误或无记录；
   - 4条候选中目标POC未出现于返回QA配对；
   - 2条缺少转换前后各至少3条匹配记录；
   - 没有候选达到强QA前后验证条件。

3. 公共监测文档：
   - 对20个预先选定事件检索EPA、州级年度监测网络计划、QAPP、维护/站点变更资料；
   - 20个都有AQS方法记录或一般方法上下文核验；
   - 0个发现有日期匹配的站点级设备/方法变更公告；
   - “没有找到公告”不等于“没有发生变化”，因此这是一项诚实的负外部验证结果。

独立参数88502敏感性
-------------------
88502与88101监管含义不同，全程独立处理，不合并主序列。

- 规范化日度记录：619,338
- 监测器时间序列：401
- 合格转换锚点：34
- 至少1个地理供体：18
- 至少3个地理供体：3
- 完成共同方法比较：3
- 因供体不足排除：31

该结果证明独立管线可运行，但样本不足以支持强泛化或统计显著性结论。

相关工作和原创性边界
----------------------
论文已经建立四类逐篇核验矩阵：
1. 空气质量数据均质化、监测器可比性与偏差校正；
2. 时间序列变点检测；
3. 合成控制、差分中的差分与参考序列均一化；
4. 公开空气质量数据、AQS元数据与可复现审计。

安全表述：
“我们未发现一个先前基准同时使用AQS报告的Method Code转换作为可复现元数据锚点、
跨站诊断对照、稳定窗口合成扰动和完整合格事件记账。”

这是一项有限文献检索表述，不是“全球首次”或绝对原创性声明。
