\section{Limitations and threats to validity}

\begin{enumerate}
  \item AQS Method Code is reported metadata, not a verified physical hardware,
  calibration, maintenance, or siting log.
  \item A station-local residual can arise from local emissions, meteorology,
  smoke, network-wide operations, data screening, or other unobserved factors.
  \item Geographic donors are selected from pre-event agreement and may not
  remain valid after an anchor; physical-site deduplication does not remove all
  reference-series uncertainty.
  \item Complete comparisons apply only to the subset with sufficient
  qualifying distinct donors and retained input windows. The full event ledger
  documents this selection boundary but cannot eliminate it.
  \item Fixed-weight intervals under-cover and split-conformal intervals
  over-cover on the frozen synthetic evaluation. Neither supports a generic
  real-event calibration claim.
  \item Selection-aware nested intervals model only the fixed observed
  candidate pool. The frozen full selection-aware synthetic coverage study was
  infeasible within the deadline, so those intervals are not claimed to have
  calibrated coverage.
  \item Time, donor-as-treated, and date-resampling placebos are diagnostic
  falsifications. They are not randomized physical experiments or causal
  probabilities.
  \item Same-site POC, QA, and official-document evidence are sparse and
  contextual. In particular, POC is not a universal physical-instrument
  identifier, and an unlocated public notice is not evidence of no change.
  \item The separate 88502 result is sparse and is not pooled with 88101.
  \item The frozen data snapshot, monitoring network, pollutant parameter,
  time period, and perturbation model limit generalization to other settings.
\end{enumerate}

The Method Code taxonomy is intentionally excluded from these results pending
independent human review. Any future stratified analysis must preserve its
frozen metadata-only rule, be labelled descriptive, and must not use the
already viewed evaluation set to select a new model or decision threshold.
