MetaShift 项目结果汇总
=======================

项目题目
--------
中文：MetaShift：基于跨站反事实的空气质量监测方法转换影响审计
英文：MetaShift: Counterfactual Attribution of Measurement-Method Shifts
      in Regulatory Air-Quality Networks

当前研究定位
------------
本项目已完成代码、数据审计、实验和可复现性阶段，并已完成外部审查提出的技术
整改。整改后的主结果已在默认环境与 requirements-lock.txt 锁定的独立环境中
重新完整构建，16 个核心结果文件哈希完全一致。

当前可以开始论文大纲、相关工作和方法章节，但仍不应直接作为最终参赛版本提交：
学生和指导老师必须先独立核验全部方法和结果，并如实完成 AI 使用、作者贡献、
指导关系和外部帮助披露。

最终路线为 MetaShift-Bench（元数据锚定审计与评测基准），而不是“MetaShift
显著优于所有基线”的算法优越性路线。两轮有边界的模型优化没有得到稳定、具有
置信区间支持的优越性，因此项目不会宣称 MetaShift 显著超过标准合成控制。

最重要的解释边界：
1. AQS Method Code 变化是“报告的测量方法发生变化”的元数据锚点。
2. 它不等于物理仪器一定被更换，也不等于已经确认的校准故障或测量偏差。
3. 本项目估计的是与方法转换相关、且不能由匹配邻站共同变化解释的局部残差
   不连续性；它不能恢复“真实污染浓度”或证明单一物理成因。

审查整改进展
------------
1. 随机种子统一
   - 主基准与消融实验已改为调用同一个 benchmark_seed 函数。
   - 在相同 80 个稳定案例、相同扰动与相同噪声上，4,000 条共同的 Standard
     synthetic-control 记录逐行完全一致。
   - estimated_log_effect、absolute_effect_error 与 ranking_score 的最大绝对差
     均为 0.0（要求不超过 1e-10）。

2. 事件级不确定性
   - 为 261 个完整真实事件的 MetaShift、Standard SC 与 Nearest-neighbor DiD
     分别计算 1,000 次循环移动块 bootstrap 条件 95% CI，共 783 条区间记录。
   - MetaShift：182 / 261 个区间排除 0。
   - Standard SC：166 / 261 个区间排除 0。
   - Nearest-neighbor DiD：154 / 261 个区间排除 0。
   - 这些区间以固定的转换前供体权重为条件，不包含供体选择和模型设定的不确定性。

3. Leave-one-donor-out 敏感性
   - 260 个事件完成所有供体移除后的重新拟合。
   - 其中 238 / 260（91.54%）在移除任一单一供体后保持效应方向。
   - 1 个事件的一次供体移除后缺少足够观测，已明确记录为不可估计，而非删除。
   - 完整事件的留一效应最大绝对偏差中位数为 0.03130 log，95% 分位数为
     0.11080 log。

4. 协议承诺修订
   - 不再承诺没有可靠标签支撑的“真实 exceptional-event 分类准确率”。
   - 已完成的环境负对照定义为：匹配的区域共同合成冲击、稳定转换后时间安慰剂
     和 donor-as-treated 站点安慰剂。
   - QA collocation 的数据不足限制仍保留并披露。

5. 可复现性和公开审计
   - 新增 requirements-lock.txt，锁定完整证据环境。
   - 新增 GitHub Actions，使用锁定依赖自动运行全部单元测试。
   - 新增安全证据包导出器，只导出配置、数据清单、汇总表、图、哈希和审计表；
     它拒绝原始 EPA 文件、AQS API 原始响应和任何凭据。

6. 整改后的最终复现
   - 默认环境和 requirements-lock.txt 锁定的独立环境均完整运行一键重建。
   - 扩展后的 16 个核心结果文件 SHA256 完全一致，其中新增事件级区间、留一供体
     敏感性、主表/消融逐行对齐和消融 bootstrap 结果。
   - GitHub Actions 使用 requirements-lock.txt 运行单元测试并已通过。

主数据：EPA AQS 参数 88101
--------------------------
时间范围：2019-2025
污染物：PM2.5 - Local Conditions
主要日度信号：24-HR BLK AVG 的 Arithmetic Mean
保留条件：Observation Percent >= 75，Method Code 非空，不使用 Event Type=Excluded

数据清洗的重要规则：
1. State / County / Site / POC 作为字符串保留，避免丢失前导零。
2. “Included”和“Excluded”可能是同一 monitor-day 的替代汇总；Excluded 记录不
   作为独立观测。
3. 同一 monitor-day 如果在清洗后仍重复，管线会报错而不是静默选择一条记录。
4. 每个原始 ZIP 的 URL、文件大小、文件修改时间、SHA256、CSV 成员和行数都记录
   在 artifacts/data_gate/data_manifest.csv。

主数据规模：
- 规范化日度记录：2,424,793
- 监测器时间序列：1,689
- Method Code 连续运行段：2,382
- 初始合格的持续方法转换锚点：563
- 至少 1 个地理供体的锚点：394
- 至少 3 个地理供体的锚点：271
- 同址替代 POC 候选：11

事件与供体规则
--------------
一个真实 Method Code 转换锚点必须满足：
1. 转换前后均至少有 60 个日历日；
2. 前后各至少 45 条符合质量门槛的日度观测；
3. 相邻方法运行段间断不超过 7 天。

地理供体站必须：
1. 位于不同物理站点；
2. 距离不超过 100 km；
3. 在目标事件 +/-60 天内自身没有 Method Code 转换；
4. 有至少 60 个转换前配对日；
5. 转换前 log(1+PM2.5) 相关系数至少为 0.60。

同址不同 POC 不进入主地理供体集合，避免把外部验证信息泄漏到主模型中。

比较方法
--------
跨站方法：
- Nearest-neighbor difference-in-differences
- Standard synthetic control
- MetaShift fixed-prior：相关性、距离和图可靠性先验的约束权重
- MetaShift CV：只用转换前时间段做内部时间验证的权重版本

单站基线：
- Before-after median
- Bayesian mean-shift
- CUSUM
- Rolling-MAD
- PELT

稳定区间合成基准
----------------
早期“在真实 Method Code 转换日期注入合成偏差”的试验已被正式淘汰，不用于论文
结论，因为真实转换点可能本来就含未知的不连续性。

最终合成基准只在目标站和已选供体都远离 Method Code 转换至少 60 天的稳定区间内
建立伪锚点：
- 80 个不同目标监测器
- 40 个监测器用于阈值校准
- 40 个互不重叠的监测器用于独立评测
- 每种扰动使用 5 个固定强度
- 每个局部或匹配区域扰动类型在独立评测中有 200 个样本
- 每种方法有 2,000 个独立评测实例
- 所有阈值只在前 40 个校准案例上选择，随后不改变地用于 40 个评测案例
- 95% CI 使用按 case_id 聚类的 1,000 次配对 bootstrap

合成扰动类型：
1. 局部固定水平跳变
2. 局部比例变化
3. 局部缓慢漂移
4. 局部暂时性偏差
5. 局部方差变化
6. 匹配的区域共同冲击

稳定合成基准主结果
--------------------
指标说明：
- MAE：局部效应幅度误差，单位为 log(1+PM2.5)，越低越好。
- AUPRC：局部变化与区域共同变化的排序区分能力，越高越好。
- Macro-F1：局部 / 区域二分类的阈值化性能，越高越好。
- FPR：区域共同冲击被错误归为局部变化的比例，越低越好。

方法                         MAE       AUPRC     Macro-F1    区域FPR
--------------------------------------------------------------------------
Standard synthetic control   0.11687   0.90559   0.82854     0.026
MetaShift fixed-prior        0.10950   0.88418   0.79825     0.094
MetaShift CV                 0.10779   0.88486   0.79416     0.141
Nearest-neighbor DiD         0.12644   0.87082   0.77779     0.109
Bayesian mean-shift          0.22414   0.50254   0.49782     0.483
Before-after median          0.24075   0.50253   0.49741     0.455
CUSUM                        无幅度估计 0.50235   0.49072     0.635
PELT                         无幅度估计 0.50234   0.49812     0.529
Rolling-MAD                  无幅度估计 0.50237   0.50252     0.528

关键解读：
1. MetaShift 在局部效应 MAE 上的点估计低于标准合成控制，但这不足以支持“显著
   优越”的结论。
2. 标准合成控制在 AUPRC、Macro-F1 和区域误报率上更好。
3. 对比例变化和方差变化，所有方法的归因能力均明显下降；这正是项目应报告的
   方法边界，而不是应该掩盖的失败结果。

配对 bootstrap：MetaShift 与标准合成控制的 MAE 差异
------------------------------------------------------
比较                                      差异(Meta - SC)    95% CI
----------------------------------------------------------------------
MetaShift fixed-prior - Standard SC       -0.00737           [-0.01845, 0.00346]
MetaShift CV - Standard SC                -0.00908           [-0.01983, 0.00193]

两个置信区间均跨过 0，因此不能宣称 MetaShift 在该基准上具有统计上稳健的
MAE 改善。这是算法优越性路线关闭的直接证据。

按扰动类型的代表性结果
------------------------
固定水平跳变：
- MetaShift fixed-prior MAE = 0.08301；Standard SC MAE = 0.08962。
- 但 Standard SC Macro-F1 = 0.975，MetaShift fixed-prior = 0.902。

缓慢漂移：
- MetaShift fixed-prior MAE = 0.08122；Standard SC MAE = 0.09177。
- Standard SC Macro-F1 = 0.970，MetaShift fixed-prior = 0.930。

比例变化：
- MetaShift fixed-prior MAE = 0.08314；Standard SC MAE = 0.09076。
- AUPRC 约为 0.81-0.83，明显低于固定水平跳变和漂移。

暂时性偏差：
- MetaShift fixed-prior MAE = 0.19061；Standard SC MAE = 0.19533。
- 短时偏差是所有跨站幅度估计方法的较难情形。

方差变化：
- 这类变化没有定义的平均水平效应 MAE。
- MetaShift fixed-prior AUPRC = 0.54999，Standard SC AUPRC = 0.56986。
- 现有残差水平评分不适合将纯方差变化可靠地归因。

关键消融结果
------------
消融在完全相同的稳定合成数据、校准/评测拆分和 bootstrap 设置下进行。

变体                                  MAE       Macro-F1    区域FPR
--------------------------------------------------------------------------
去 ridge 正则                          0.10779   0.79996     0.097
直接使用可靠性先验                    0.10891   0.79398     0.093
加入配对覆盖率                        0.10938   0.79838     0.085
完整相关性+距离 MetaShift             0.10950   0.79667     0.094
去相关性                              0.10989   0.79746     0.088
去图先验                              0.11114   0.79566     0.095
去距离                                0.11186   0.79575     0.097
均匀先验                              0.11196   0.79394     0.104
Standard synthetic control             0.11687   0.81665     0.025

消融结论：
1. 相关性、距离、覆盖率和正则化会影响效果估计，但没有单一组件显示出对标准
   合成控制稳定、置信区间支持的优势。
2. 不应把某个轻微点估计改善包装成新的通用算法贡献。
3. 这些结果支持将可复现评测协议、错误模式和适用边界作为论文核心贡献。

MetaShift fixed-prior 的质量门控：

“这些是 Method Code 转换相关的、相对匹配供体的局部残差效应估计。”

不正确的表述：
“这些是已经确认的仪器故障、校准误差或真实污染浓度修正值。”

安慰剂与负对照
--------------
1. 时间安慰剂
   - 261 个完整真实事件中，167 个拥有 10 个转换后稳定方法区间伪日期。
   - 61 / 167 个真实锚点的经验 placebo p-value <= 0.10。
   - 89 / 167 个真实锚点的经验 placebo p-value <= 0.20。
   - 94 个事件因无法获得足够稳定的转换后伪日期而明确记为不可校准。

2. 供体作为伪处理站
   - 1,050 条 donor-as-treated placebo 记录。
   - 44 个真实事件因移除伪处理供体后不足 3 个控制站而明确排除。
   - 伪处理站标准化分数中位数 = 0.46802。

3. 200 次日期重采样
   - 有完整时间安慰剂的事件数：167。
   - 真实 Method Code 锚点平均绝对标准化分数：0.90968。
   - 重采样稳定后伪日期平均分数：0.48573。
   - 全局上尾 p-value：0.004975。

安慰剂结论：
真实元数据锚点在统计上通常比同一序列的稳定后日期更异常，但这种异常性仍不能
单独确定是仪器、方法、局地排放、站点条件、数据处理还是未观测环境因素造成。

同址 POC 与 QA collocation 外部证据
------------------------------------
同址替代 POC：
- 11 个候选均有可用的前后配对记录。
- 它们用于减少空间环境差异、作为“分级外部一致性证据”。
- POC 不是统一的物理仪器编号：同一 POC 可在设备替换后继续使用，因此不能把
  POC 结果说成绝对设备真值。

EPA QA collocation API：
- 6 条候选请求为 API 错误或无记录。
- 4 条候选中目标 POC 未出现在返回的 QA 配对里。
- 2 条 QA 配对缺少转换前后各至少 3 条匹配记录。
- 没有一个候选同时满足“目标 POC 匹配 + 足够前后 QA 记录”的强 QA 验证条件。

QA 结论：
QA 数据是补充性证据源，但在当前样本中不足以做强的总体外部验证。论文必须公开
这一限制，不能把“调用过 QA API”写成“QA 已确认方法偏差”。

独立敏感性分析：参数 88502
-----------------------------
88502 与 88101 的监管含义不同，因此全程独立处理，绝不合并为一条主序列。

88502 数据：
- 规范化日度记录：619,338
- 监测器时间序列：401
- Method Code 运行段：457
- 合格转换锚点：34
- 至少 1 个地理供体：18
- 至少 3 个地理供体：3

88502 结论：
该分析可证明管线在独立参数代码上可运行，但由于只有 3 个完整比较事件，不能用
它做强泛化或统计显著性结论。

最终结论
--------
本项目最可靠的成果不是“一个在所有情形下胜过标准合成控制的新算法”，而是：

1. 一个可从公开 EPA AQS 原始文件完整重建的 563 事件 Method Code 转换基准；
2. 一套明确区分局部测量相关不连续性和区域共同变化的跨站反事实审计协议；
3. 一个覆盖稳定合成真值、真实元数据锚点、同址 POC、QA 数据和多种安慰剂的
   分层证据框架；
4. 对 MetaShift、标准合成控制、邻站 DiD 和单站变点方法在不同扰动形态下成功/
   失败条件的量化比较；
5. 对供体不足、预拟合质量、短时效应、比例变化、方差变化和 QA 样本不足等
   局限的完整记录；
6. 两个独立 Python 环境下的完整复现验证。
