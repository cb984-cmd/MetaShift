MetaShift-Bench 项目结果汇总
============================

证据版本与使用边界
------------------

本汇总只报告冻结的 `v0.3.2-evidence-final` 证据版本：

- 证据提交：`57d678ecabebff724d898abe626c9ef80538775b`
- Release：https://github.com/cb984-cmd/MetaShift/releases/tag/v0.3.2-evidence-final
- 合成基准标签：`stable_full_v2`
- release gate：35/35；文档一致性：12/12；论文数字校验：57/57。
- 默认环境和 `requirements-lock.txt` 环境对 34 个指定核心结果文件的
  SHA-256 完全一致。

`v0.3.0-distinct-donors` 和 `v0.3.1-evidence-final` 均为保留的历史
（superseded）版本，已由本版本替代，不得用于当前科学结论。

项目主线是“可复现的元数据锚定审计基准”，不是“MetaShift 算法显著优于
所有基线”。AQS Method Code 变化只定义一个报告的测量方法变化日期；它不证明
物理仪器更换、仪器故障、校准问题或因果测量偏差。跨站反事实得到的是与元数据
锚点相关的局部残差不连续性诊断，不是污染浓度修正值。

数据与事件规模
--------------

主数据为 EPA AQS 2019--2025 年参数 88101（PM2.5 Local Conditions）日度记录。
规范化信号为 `24-HR BLK AVG` 的 `Arithmetic Mean`；保留 Observation Percent
至少 75、Method Code 非空且 Event Type 不为 `Excluded` 的记录。

- 规范化日度记录：2,424,793
- 监测器时间序列：1,689
- 持续 Method Code 转换元数据锚点：563
- 至少一个不同物理地理供体的锚点：394
- 至少三个不同物理地理供体的锚点：238
- 同址替代 POC 候选：11

地理供体必须来自不同物理站点、距离不超过 100 km、在目标锚点前后 60 天内
自身没有 Method Code 转换、具有至少 60 个转换前配对日，且转换前
`log(1 + PM2.5)` 相关系数至少为 0.60。同址 POC 不作为主地理供体。

稳定区间合成基准
----------------

合成锚点仅从目标和选中供体均远离 Method Code 转换至少 60 天的稳定区间构造。
基准包含 146 个不同物理目标站点：66 个用于阈值校准，80 个用于独立评测。
两个拆分的完整目标加供体物理输入足迹零重叠。每种局部或匹配区域扰动有 400 个
评测样本，阈值只在校准拆分确定。

MAE 单位为 `log(1 + PM2.5)`，越低越好；AUPRC 和 Macro-F1 越高越好；
区域 FPR 越低越好。

方法                           MAE       AUPRC     Macro-F1    区域FPR
----------------------------------------------------------------------------
Standard synthetic control     0.09983   0.91476   0.81641     0.140
MetaShift 固定可靠性先验       0.10344   0.89832   0.79515     0.150
MetaShift 转换前交叉验证       0.09742   0.90178   0.80916     0.135
Nearest-neighbor DiD           0.11150   0.88443   0.78852     0.075

固定可靠性先验 MetaShift 相对 Standard SC 的配对 MAE 差异为 0.00361，
95% CI [-0.00401, 0.01163]；转换前交叉验证 MetaShift 的差异为 -0.00240，
95% CI [-0.00772, 0.00347]。两个区间均跨过零。因而现有盲测结果不支持
MetaShift 相对 Standard synthetic control 的稳定、置信区间支持的总体优势。

主基准与可靠性消融共享的 7,300 条 Standard synthetic-control 记录逐行一致，
最大允许差异为 1e-10。

全量真实锚点审计
----------------

所有 563 个元数据锚点均保留在审计表中：

审计状态                                  数量
------------------------------------------------
完成共同方法比较                           228
少于三个不同物理地理供体                   325
估计器输入窗口失败                          10
总计                                      563

228 个完整比较中的 60 日中位有符号 log 残差效应分别为：

方法                           中位 log 效应
------------------------------------------------
MetaShift 固定可靠性先验       -0.08704
Standard synthetic control     -0.07078
Nearest-neighbor DiD           -0.07490

这些量是观察性诊断估计，不是已确认的仪器偏差标签。基于预先固定诊断规则，
证据层级为 34 个 supported candidate、122 个 not supported 和 407 个
inconclusive。层级用于审计和案例选择，绝不是物理仪器故障或因果标签。

不确定性、安慰剂与敏感性
----------------------

- 228 个完整事件均有固定权重条件区间；MetaShift、Standard SC、DiD 分别有
  159/228、145/228、134/228 个区间排除零。
- 227/228 个完整事件有选择感知嵌套区间，153 个排除零；其平均宽度为
  0.19057 log units。该区间只在固定观测候选池内重选供体和重拟合权重，
  并非物理偏差的覆盖率校准置信区间。
- 227 个事件完成全部 leave-one-donor-out 重新拟合，202 个在每一次供体移除后
  保持效应方向。
- 时间安慰剂可用于 157/228 个完整事件，其中 128 个有 100 个稳定伪日期；
  200 次日期重采样的上尾概率为 0.00498，donor-as-treated 表有 866 条记录，
  标准化分数中位数为 0.40831。这些是诊断性反证工具，不是因果概率。
- 固定权重 nominal 95% 移动块区间在合成评测的经验覆盖率为
  63.875%--67.281%，每种方法有 3,200 个效应实例；nominal 90%
  split-conformal 区间为 98.8125%--99.5625%。前者欠覆盖，后者高度保守。
- 全供体重选的 selection-aware 合成覆盖率协议在截止期内
  `infeasible_within_deadline`。因此真实事件的选择感知区间不能描述为具有
  95% 实际覆盖率。

外部上下文与独立敏感性
----------------------

- 11 个同址替代 POC 候选中，9 个具有可用小时配对，日度/小时方向在 8/9 个案例
  中一致；这只是空间控制的上下文证据。
- QA collocation 审计有 12 个候选、2 个目标 POC 匹配、0 个具有充分匹配的
  转换前后窗口；不能将其称为物理真值验证。
- 对 20 个预先选定官方文件案例的审阅得到 0/20 个有日期的站点级确认。未找到
  公告不等于不存在物理变化。
- 独立参数 88502 管线有 34 个元数据锚点和 3 个完整比较，样本量不足以支持
  强泛化结论，且从不与 88101 主结果混合。

方法实现窗口的限制
------------------

当前冻结实现对固定权重拟合和残差中心化使用包含端点的
`t0-180 through t0-15`（166 个日历日）；效应比较使用包含端点的转换前 60 日
和转换后 60 日。拟合窗口与效应的转换前窗口有 46 个日期重叠。没有转换后
结果用于拟合，但转换前残差不是独立验证集；本限制已公开记录，不在事后重新调参。

复现与人工事项
--------------

源数据、结果路径、哈希和生成配置均由
`configs/current_evidence_summary_v2.json` 绑定；正式报告使用
`paper/latex/` 中的确定性表格和矢量图生成器。公开证据包不包含 EPA 原始 ZIP、
AQS API 原始响应、凭据、虚拟环境或缓存。

以下事项必须由学生、指导教师或学校完成，项目不会自动标记为已完成：

1. Method Code taxonomy 逐行人工审核，以及任何 taxonomy 分层分析。
2. 学生对方法、代码、证据和限制的独立理解确认。
3. 作者贡献、指导关系、报酬、外部帮助与 AI 使用的如实披露。
4. 学生和指导老师签字、学校/单位盖章、查重、学术诚信声明和最终真实性确认。
