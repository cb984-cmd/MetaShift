# Targeted public-document review of 20 preselected metadata anchors

**Purpose:** seek independent public context for selected AQS Method Code
boundaries. This review does **not** treat a reported Method Code boundary as a
physical instrument replacement, and it does not use an absence of a document
as evidence that no physical change occurred.

## Selection and classification protocol

Twenty anchors were selected before document retrieval from the audit's
high-signal candidate list. The document reviewer received event identifiers,
dates, and method labels but not effect scores or tier labels. Searches covered
official state/local monitoring portals, annual monitoring network plans,
quality-assurance plans, site-change or maintenance notices, EPA AirData, and
EPA method documentation.

| Class | Meaning |
| --- | --- |
| 1 | A public source explicitly confirms a site-specific method or instrument change with a matching date. |
| 2 | An official source corroborates the AQS method-record context or general method context, but no dated site-specific change notice was located. |
| 3 | No relevant public record was located after documented searches. This is not evidence of no change. |
| 4 | A potentially relevant public document was unavailable or inaccessible. |

**Result:** all 20 records are class 2. The review found no class-1,
site-specific dated confirmation. This is a negative external-validation
result and remains a limitation of the study.

## General method context

- EPA's [May 2024 supplemental information on the T640/T640X data
  update](https://www.epa.gov/system/files/documents/2024-05/2_supplemental-info_t640-data-update_final-05-13-2024.pdf)
  describes the broader NDA-related data update. It does not supply a
  site-specific dated notice for the events above.
- EPA's [T640X standard operating procedure](https://nepis.epa.gov/Exe/ZyPURL.cgi?Dockey=P101D17I.txt),
  pp. 5--6, distinguishes the PM2.5 FEM configurations corresponding to T640
  (236) and T640X (238). It does not document a listed site's transition.
- EPA's [POC definition](https://aqs.epa.gov/aqsweb/documents/codingmanual/html/fromdatabase/POC.html)
  explains why POC cannot be treated as a physical-instrument identifier.
